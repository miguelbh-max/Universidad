Sistemas Operativos

El motor invisible que da vida a la tecnología.

¿Qué es y para qué sirve?

El Concepto

Un Sistema Operativo (SO) es el software principal que gestiona el hardware de la computadora. Actúa como intermediario entre el usuario y los componentes físicos.

Su Utilidad

Administra la memoria, los procesos, los archivos y los periféricos. Sin él, cada programa tendría que manejar los detalles del hardware por sí mismo.

Evolución Histórica

En los inicios, las computadoras como la ENIAC no tenían sistemas operativos. Los programadores interactuaban directamente con el hardware usando lenguaje máquina y tarjetas perforadas. Solo se ejecutaba una tarea a la vez.

General Motors desarrolló el primer SO de la historia (GM-NAA I/O) para la IBM 704. Introdujo el procesamiento por lotes (batch processing), donde los trabajos similares se agrupaban y ejecutaban secuencialmente para ahorrar tiempo de configuración.

Nace Multics y posteriormente UNIX. Se introduce la multiprogramación, permitiendo que la memoria albergue múltiples programas a la vez, y el tiempo compartido, dando la ilusión de que varios usuarios interactúan con el sistema simultáneamente.

Sistemas como MS-DOS dominan el mercado de las computadoras personales. Posteriormente, Apple (Lisa/Macintosh) y Microsoft (Windows) introducen la Interfaz Gráfica de Usuario (GUI), usando ventanas, íconos y ratón, revolucionando la accesibilidad.

Sistemas Modernos

Microsoft Windows

El sistema operativo comercial más utilizado en computadoras de escritorio a nivel mundial.

  • Interfaz intuitiva y altamente estandarizada.
  • Máxima compatibilidad con software comercial y videojuegos.
  • Enfoque principal en la facilidad de uso para el usuario promedio.

Ubuntu (Linux)

Una de las distribuciones de GNU/Linux más populares, basada en Debian y de código abierto.

  • Alta seguridad y menor susceptibilidad a virus.
  • Completamente gratuito y personalizable.
  • Excelente rendimiento en desarrollo, servidores y sistemas de bajos recursos.
