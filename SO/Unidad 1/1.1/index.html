1.1 Comandos Esenciales de Navegación y Manipulación

Antes de administrar un sistema operativo hay que saber moverse en él. Estos son los comandos con los que vivirás todos los días en la terminal de Ubuntu.

¿Por qué la terminal?

En Linux, la interfaz de línea de comandos (CLI) es la forma más directa y potente de operar el sistema operativo: cada acción que haces con el mouse tiene un comando equivalente, más rápido y automatizable.

Lo que dominarás aquí

Navegar entre carpetas, listar contenido, crear y copiar archivos, moverlos o eliminarlos, y ver su contenido — la base de cualquier práctica de este curso.

Referencia rápida

Comandos por categoría

pwd
pwd
Print Working Directory. Muestra la ruta absoluta de la carpeta donde estás parado en ese momento.
ls
ls · ls -l · ls -la · ls -lh
Lista el contenido del directorio actual. -l formato largo (permisos, dueño, tamaño); -a incluye ocultos; -h tamaños legibles (K, M, G).
cd
cd carpeta · cd .. · cd ~
Change Directory. Entra a una carpeta, sube un nivel con .., o regresa a tu carpeta personal con ~.
mkdir
mkdir -p directorio/subdirectorio
Crea directorios. La opción -p genera también las carpetas padre si aún no existen.
touch
touch archivo.txt
Crea un archivo vacío, o actualiza su fecha de modificación si ya existe.
cp
cp origen destino · cp -r dir1 dir2
Copia archivos. La opción -r (recursivo) es obligatoria para copiar carpetas completas.
mv
mv origen destino
Mueve o renombra archivos y carpetas — internamente solo cambia el puntero en el sistema de archivos, no copia los datos.
rm
rm archivo · rm -r carpeta
Elimina el enlace del archivo en el inodo. -r borra carpetas completas. ⚠️ No existe papelera de reciclaje en la terminal.
cat
cat archivo.txt
Concatena y muestra el contenido completo de un archivo de texto directamente en la terminal.
nano
nano archivo.txt
Abre un editor de texto interactivo dentro de la terminal. Guardar: Ctrl+O · Salir: Ctrl+X.
Practica sin abrir Ubuntu

Simulador de terminal

alumno@ubuntu: ~
alumno@ubuntu:~$ _
