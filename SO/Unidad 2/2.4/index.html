2.4 ¿Cómo Hacerlo Ejecutable?

Un script recién guardado no se puede ejecutar todavía. Aquí entra chmod +x.

¿Por qué falla al principio?

Por seguridad, los editores de texto crean archivos nuevos sin el bit de ejecución (permisos 644 o 664). El sistema se niega a correrlo aunque el contenido sea correcto.

La solución

chmod +x archivo.sh agrega el permiso de ejecución a todos los niveles. A partir de ahí, ./archivo.sh funciona con normalidad.
