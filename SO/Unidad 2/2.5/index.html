2.5 ¿Dónde se Debe Guardar un Script?

La carpeta donde vive tu script decide cómo lo vas a poder ejecutar después.

Elige el escenario

Uso personal vs. comando global

Guardar en tu carpeta personal

Para uso propio, el script se guarda en tu carpeta personal, normalmente dentro de una subcarpeta como ~/scripts/. Solo se puede ejecutar indicando la ruta relativa o completa.

mkdir -p ~/scripts mv mi_script.sh ~/scripts/ ~/scripts/mi_script.sh

Convertirlo en comando del sistema

Para poder escribir el nombre del script desde cualquier carpeta sin usar ./ ni la ruta completa, se copia a /usr/local/bin/ — una carpeta que ya forma parte de la variable $PATH del sistema.

sudo cp mi_script.sh /usr/local/bin/monitor-so sudo chmod 755 /usr/local/bin/monitor-so monitor-so # funciona desde cualquier carpeta

Preguntas y respuestas

Es una lista de carpetas donde Linux busca automáticamente un comando cuando escribes su nombre. Si tu script está en una de esas carpetas, no necesitas escribir la ruta completa.
Porque esa carpeta es del sistema, no de tu usuario. Modificarla requiere privilegios de superusuario para evitar que cualquier programa instale comandos ahí sin autorización.
