2.1 ¿Qué es un Script y por qué se usa?

Automatiza en segundos lo que tomaría minutos escribir a mano, comando por comando.

¿Qué es un script?

Un archivo de texto plano que contiene una secuencia ordenada de comandos del sistema operativo. El script los ejecuta uno tras otro, de forma automática.

¿Por qué se usa?

En lugar de escribir 10 comandos manualmente cada vez que se arranca un servicio o se hace un respaldo, el script ejecuta todo en un segundo — siempre igual, sin errores de captura.

La diferencia en la práctica

Sin script vs. con script

⏱️ Sin script — 4 comandos a mano
$ date
$ free -h
$ df -h /
$ echo "Reporte generado"
Repetir esto cada vez que necesitas el reporte, sin errores de dedo.
⚡ Con script — 1 comando
$ ./monitor_sistema.sh
→ ejecuta las mismas 4 tareas automáticamente
Un solo comando, siempre el mismo resultado, cero errores.
