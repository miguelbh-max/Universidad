2.2 ¿Por qué la extensión .sh?

Mito vs. realidad: en Linux, la extensión del archivo no es lo que decide cómo se ejecuta.

Compara los dos sistemas

Windows vs. Linux: ¿quién decide cómo ejecutar un archivo?

Mito: "la extensión decide todo"

En Windows, la extensión (.exe, .bat) sí le indica al sistema operativo cómo tratar el archivo. Cambiar la extensión puede romper la forma en que se ejecuta.

archivo.exe → el SO lo reconoce como programa ejecutable

Realidad en GNU/Linux

El kernel de Linux no usa la extensión para decidir nada: analiza el contenido real del archivo (sus primeros bytes). Usamos .sh solo por convención humana, y para que editores como nano o VS Code activen el coloreado de sintaxis.

archivo.sh, archivo.txt o archivo sin extensión → todos pueden ejecutarse igual si tienen permiso y shebang
Interactivo · pasa el cursor

Lo que sí decide la ejecución: el Shebang

# ! /bin/bash
Pasa el cursor sobre cada parte del Shebang para ver su función.
