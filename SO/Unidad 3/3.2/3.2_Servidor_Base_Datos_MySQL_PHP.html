Unidad 3: Servidores en el S.O. Sección 3.2 MySQL (Puerto 3306) PHP + phpMyAdmin

Servidor MySQL, Intérprete PHP y phpMyAdmin

Guía de instalación y configuración de la pila LAMP completa en Ubuntu Desktop.

1

MySQL Server: Base de Datos Relacional

¿Qué es MySQL? Es un Sistema de Gestión de Bases de Datos Relacionales (RDBMS) de alto rendimiento basado en el lenguaje SQL. Escucha por defecto en el puerto de red TCP 3306.

¿Para qué sirve? Permite almacenar, organizar, indexar y consultar información estructurada (usuarios, productos, transacciones o sesiones) de aplicaciones web.

Paso 1.1: Instalación de MySQL Server

Ejecuta en tu terminal el siguiente comando:

bash — terminal
$ sudo apt install mysql-server -y

Paso 1.2: Asegurar la instalación (Security Script)

Ejecuta el script de endurecimiento para eliminar accesos anónimos y bases de datos de prueba:

bash — terminal
$ sudo mysql_secure_installation
Opciones recomendadas en el asistente:
  • VALIDATE PASSWORD COMPONENT: Puedes responder n si es un entorno de laboratorio educativo, o y (Medium o Strong) en producción.
  • Remove anonymous users?: Responde y.
  • Disallow root login remotely?: Responde y.
  • Remove test database and access to it?: Responde y.
  • Reload privilege tables now?: Responde y.

Paso 1.3: Verificación del servicio

bash — terminal
$ sudo systemctl status mysql
2

PHP: Intérprete y Conexión con Apache y MySQL

¿Qué es PHP? Es un lenguaje de programación interpretado del lado del servidor (Server-Side Scripting) diseñado para el desarrollo de páginas web dinámicas.

¿Para qué sirve? Procesa la lógica de negocio, se comunica con la base de datos MySQL y genera dinámicamente el HTML final que Apache entrega al navegador del cliente.

Paso 2.1: Instalación de PHP y sus módulos esenciales

Instalamos el motor PHP, el módulo para integrarlo con Apache y la extensión para dialogar con MySQL:

bash — terminal
$ sudo apt install php libapache2-mod-php php-mysql -y

Paso 2.2: Creación de un script de prueba (info.php)

Generamos un archivo PHP en la raíz pública del servidor web para comprobar la interpretación:

bash — terminal
$ echo "<?php phpinfo(); ?>" | sudo tee /var/www/html/info.php

Reinicia Apache para cargar los módulos de PHP:

bash — terminal
$ sudo systemctl restart apache2

Paso 2.3: Verificación en el navegador

Abre tu navegador e ingresa a:

navegador
http://localhost/info.php
¡Advertencia de Seguridad! La página phpinfo() expone información sensible sobre módulos y rutas del sistema. Al terminar tus pruebas en entornos reales, bórrala con:
sudo rm /var/www/html/info.php
3

phpMyAdmin: Administración Gráfica Web de MySQL

¿Qué es phpMyAdmin? Es una herramienta web escrita en PHP orientada a administrar servidores MySQL/MariaDB a través de una interfaz gráfica intuitiva, eliminando la necesidad de interactuar solo por línea de comandos.

Paso 3.1: Instalación de paquetes necesarios

bash — terminal
$ sudo apt install phpmyadmin php-mbstring php-zip php-gd php-json php-curl -y
Atención a las ventanas del asistente en la terminal:
  1. Servidor web a configurar: Selecciona [*] apache2 presionando la Barra Espaciadora para marcar el asterisco, y luego pulsa Enter.
  2. ¿Configurar base de datos para phpmyadmin con dbconfig-common?: Selecciona <Sí> / <Yes>.
  3. Contraseña para phpmyadmin: Ingresa una clave segura o déjalo en blanco para autogenerar una.

Habilita la extensión mbstring y reinicia Apache:

bash — terminal
$ sudo phpenmod mbstring
$ sudo systemctl restart apache2

Paso 3.2: Creación de usuario administrador para el acceso web

Por defecto en Ubuntu, el usuario root de MySQL se autentica mediante el plugin auth_socket a nivel de sistema operativo y no permite login directo vía formulario web con contraseña. Por ello, creamos un usuario dedicado:

bash — terminal
$ sudo mysql

Dentro del intérprete de comandos de MySQL (mysql>), ejecuta una por una:

mysql shell
mysql> CREATE USER 'admin'@'localhost' IDENTIFIED WITH mysql_native_password BY 'TuClaveSegura123!';
mysql> GRANT ALL PRIVILEGES ON *.* TO 'admin'@'localhost' WITH GRANT OPTION;
mysql> FLUSH PRIVILEGES;
mysql> EXIT;

Paso 3.3: Acceso al panel web

Abre el navegador e ingresa a:

navegador
http://localhost/phpmyadmin
Acceso concedido: Ingresa el usuario admin y la contraseña definida (TuClaveSegura123!). Ahora tendrás acceso a la consola gráfica completa para crear bases de datos, tablas y ejecutar sentencias SQL.
