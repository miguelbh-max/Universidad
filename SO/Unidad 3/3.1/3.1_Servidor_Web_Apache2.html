Unidad 3: Servidores en el S.O. Sección 3.1 Ubuntu Desktop Puerto TCP 80

Instalación y Configuración de Apache2

Guía de laboratorio paso a paso para desplegar un servidor HTTP en Linux.

1

Introducción: ¿Qué es Apache2?

Apache HTTP Server (Apache2) es uno de los servidores web de código abierto más utilizados, robustos y confiables a nivel mundial. Es administrado por la Apache Software Foundation.

¿Para qué sirve? Su función principal es recibir peticiones de clientes (navegadores web) a través del protocolo HTTP (puerto estándar TCP 80) o HTTPS (puerto estándar TCP 443), y entregar archivos HTML, imágenes, hojas de estilo o reenviar peticiones a procesadores dinámicos como PHP.

Ubicación de archivos clave en Ubuntu:
  • Directorio raíz por defecto para páginas web: /var/www/html/
  • Directorio principal de configuración: /etc/apache2/
  • Archivo de registro de errores (logs): /var/log/apache2/error.log
2

Requisitos previos y preparación

Antes de instalar cualquier software nuevo en Ubuntu, es una buena práctica actualizar el índice de los repositorios de paquetes (APT) y elevar las librerías del sistema a su versión más reciente.

Abre la terminal de Ubuntu (atajo: Ctrl + Alt + T) y ejecuta:

bash — terminal 
$ sudo apt update && sudo apt upgrade -y
Nota sobre privilegios: El comando sudo solicitará tu contraseña de usuario administrador. Recuerda que al escribirla en la terminal de Linux no se mostrarán asteriscos por seguridad.
3

Instalación paso a paso de Apache2

Apache se encuentra en los repositorios oficiales de Ubuntu. Ejecuta el comando de instalación:

bash — terminal 
$ sudo apt install apache2 -y

Una vez concluida la descarga e instalación, Ubuntu iniciará y habilitará automáticamente el servicio de Apache para que arranque con el encendido de la máquina.

4

Verificación, Firewall y Pruebas

Paso A: Verificar el estado del servicio

Comprueba que el demonio apache2 se encuentre activo y en ejecución (active (running)):

bash — terminal
$ sudo systemctl status apache2
Tip: Si la salida te deja en modo visor, presiona la tecla Q para regresar a la terminal.

Paso B: Configurar el Firewall (UFW)

Si tienes activado el cortafuegos Uncomplicated Firewall (UFW), debes habilitar el tráfico entrante en el puerto 80 TCP:

bash — terminal
$ sudo ufw allow 'Apache'
$ sudo ufw reload
$ sudo ufw status

Paso C: Comprobación en el navegador web

Abre Firefox o Google Chrome en tu Ubuntu Desktop e ingresa en la barra de direcciones:

navegador
http://localhost

O si deseas consultarlo desde otra máquina en la misma red local, averigua tu IP con:

bash — terminal
$ hostname -I | awk '{print $1}'
Resultado exitoso: Deberás observar la página por defecto titulada "Apache2 Ubuntu Default Page - It works!". Esto confirma que el servidor web está operando y escuchando en el puerto TCP 80.
