Clasificación de los Sistemas Operativos

Un mismo propósito, decenas de arquitecturas distintas. Así se ordenan los sistemas operativos según cómo administran usuarios, tareas, procesadores y estructura interna.

Resumen

¿Por qué clasificar un sistema operativo?

Todo sistema operativo administra los mismos recursos —procesador, memoria, dispositivos y archivos— pero lo hace de forma distinta según el tipo de usuario, la carga de trabajo y el hardware para el que fue diseñado. Clasificarlo permite comparar arquitecturas y elegir la más adecuada para cada contexto.

Las categorías no son excluyentes: un mismo sistema operativo moderno suele combinar varios criterios a la vez (por ejemplo, multiusuario, multitarea y de estructura cliente-servidor).
