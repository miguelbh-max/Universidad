Aprende a comunicarte con la IA para obtener el código perfecto para tu proyecto web.

🧠 Claude

📝 Instrucciones Clave para el Alumno

  • 1
    Define claramente el propósito

    Antes de redactar el prompt, ten claro de qué trata tu página y qué secciones tendrá.

  • 2
    Solicita estructura y archivos separados

    Pide a la IA que genere el HTML, los estilos CSS y la interacción en JavaScript en archivos separados (o integrados según el alcance del proyecto).

  • 3
    Revisa y prueba localmente

    Abre el archivo index.html en tu navegador y comprueba que todo funcione correctamente antes de subirlo.

02 Publicación y Despliegue en GitHub

El proceso para alojar tu página y obtener una URL pública funcional.

📁

1. Crear Repositorio

Inicia sesión en GitHub y crea un nuevo repositorio público. Dale un nombre claro y descriptivo a tu proyecto.

⬆️

2. Subir Archivos

Sube los archivos de tu proyecto al repositorio. Importante: asegúrate de que tu archivo principal se llame index.html.

🚀

3. Activar Pages

Ve a la pestaña Settings > Pages, selecciona la rama main (o master) como origen y guarda para desplegar.

🤖 Integración con IA en el despliegue

Tip pro: Indica a la IA la estructura de tu repositorio para que te ayude a configurar o verificar tu enlace público resultante.

Ejemplo: https://tu-usuario.github.io/nombre-del-repositorio/
