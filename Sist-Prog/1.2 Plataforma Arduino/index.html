¿Qué es Arduino?

Arduino es una plataforma de creación de electrónica de código abierto, basada en hardware y software fácil de usar. Está diseñado para que cualquier persona pueda crear proyectos interactivos.

Hardware Libre

Planos y esquemas disponibles para todos. Puedes modificar o crear tus propias versiones de las placas.

Fácil de Usar

El software IDE de Arduino es fácil para principiantes, pero lo suficientemente flexible para usuarios avanzados.

Gran Comunidad

Millones de usuarios comparten código, librerías y soluciones. Nunca estarás solo si tienes un problema.

Multiplataforma

El entorno de desarrollo (IDE) funciona en Windows, macOS y Linux. Además de contar con un IDE en la nube.

El Lenguaje de Arduino

El código en Arduino (llamado Sketch) oculta los detalles complejos del microcontrolador. Todo programa requiere principalmente dos funciones: setup() y loop().

Manejo de Pines (I/O)

  • pinMode(pin, mode) Configura el pin como entrada (INPUT) o salida (OUTPUT).
  • digitalWrite(pin, val) Escribe un valor ALTO (5V) o BAJO (0V) en el pin.
  • digitalRead(pin) Lee el estado actual del pin.
  • analogRead(pin) Lee un voltaje y lo convierte en un número (ej. 0-1023 en placas de 10 bits de resolución ADC).
  • analogWrite(pin, val) Genera una onda PWM para simular valores analógicos (útil para variar el brillo de LEDs o la velocidad de motores).
Blink_Button.ino 
// Ejemplo: Control de LED con botón y lectura serial

const int ledPin = 13;   // Pin del LED integrado
const int btnPin = 2;    // Pin de un botón

void setup() {
  // setup() se ejecuta UNA VEZ al iniciar
  pinMode(ledPin, OUTPUT);
  pinMode(btnPin, INPUT_PULLUP);
  
  // Iniciar comunicación serial
  Serial.begin(9600);
  Serial.println("Sistema iniciado.");
}

void loop() {
  // loop() se ejecuta REPETIDAMENTE
  int btnState = digitalRead(btnPin);
  
  if (btnState == LOW) { // Botón presionado (Pull-up)
    digitalWrite(ledPin, HIGH);
    Serial.println("LED Encendido");
  } else {
    digitalWrite(ledPin, LOW);
  }
  
  delay(50); // Pequeña pausa anti-rebote
}
Versus

Arduino Clásico vs ESP32

¿Por qué el SoC ESP32 ha complementado tan bien al ecosistema Arduino para proyectos del Internet de las Cosas (IoT)?

Arduino UNO R3

El estándar clásico (Microcontrolador ATmega328P)

  • Arquitectura 8-bit AVR
  • Reloj 16 MHz
  • RAM / Flash 2 KB / 32 KB
  • Conectividad Ninguna
  • Lenguaje C/C++ (Arduino IDE)
  • Casos de Uso Robótica básica, aprendizaje escolar, sensores simples.
El Rey del IoT

SoC ESP32

El estándar moderno (Tensilica Xtensa Dual-Core)

  • Arquitectura 32-bit Dual-Core
  • Reloj Hasta 240 MHz
  • RAM / Flash 520 KB / 4 MB+
  • Conectividad WiFi & Bluetooth/BLE
  • Lenguaje C/C++, MicroPython, Lua
  • Casos de Uso Domótica, Web Servers, Smart Home, Edge AI.

¡Atención! La línea divisoria se ha difuminado. Arduino ha lanzado placas oficiales (como el Nano ESP32) que integran este potente chip, fusionando lo mejor de ambos mundos: el ecosistema Arduino y la potencia de Espressif.

Catálogo de Última Generación

Descubre el hardware que está revolucionando la comunidad maker profesional. Arquitecturas de 32 bits, matrices LED y conectividad total.

WiFi + Matrix

Arduino UNO R4

El clásico reinventado. Incorpora un microcontrolador ARM Cortex-M4 de 32 bits (Renesas RA4M1), conector USB-C y conectividad. Lenguaje: Se programa principalmente en C/C++ clásico.

C/C++ Cortex-M4 USB-C
IoT Micro

Arduino Nano ESP32

El poder del chip ESP32-S3 empaquetado en el formato Nano. Ideal para IoT. Lenguaje: Se programa de forma nativa en C/C++ (Arduino IDE) y MicroPython.

C/C++ MicroPython Wi-Fi/BLE
Pro Level

Arduino GIGA R1 WiFi

Alto rendimiento (Dual-Core Cortex-M7/M4) para proyectos pesados (cámara, audio). Lenguaje: C/C++ clásico y soporte oficial para MicroPython.

C/C++ MicroPython Dual-Core
Industry

Arduino PRO / Opta

Dispositivos para la industria (PLC modular). Lenguaje: Compatible con C/C++ y lenguajes estándar de PLC como IEC 61131-3 (Diagrama de Contactos / Ladder).

C/C++ PLC Ladder IEC 61131-3
AI & Linux

Arduino UNO Q

La bestia híbrida. Combina procesador Qualcomm (Linux/IA) y MCU STM32. Lenguaje: C/C++ (para MCU) y lenguajes Linux como Python, Node.js y Bash.

C/C++ Python/Linux Edge AI
