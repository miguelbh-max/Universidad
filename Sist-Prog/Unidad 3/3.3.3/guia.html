Filtro complementario con servo

Un servo que muestra el ángulo estimado por el filtro, con la IMU simulada en el código.

1× Arduino Uno R31× Micro servo

1 · El circuito terminado

Colores: rojo = 5 V, naranja = señal, café = GND.

2 · Pasos de armado

  1. Tinkercad → Circuits → Circuito nuevo y arrastra un Arduino Uno R3.
  2. Agrega un Micro servo: señal al pin D9, rojo a 5V y café (o negro) a GND.
  3. Abre el Monitor serie desde el panel de código.
Tinkercad no trae el MPU6050. El código genera un acelerómetro con ruido y un giroscopio con deriva a partir de un ángulo conocido, y el filtro los combina.

4 · Cómo probar

Con el código cargado, el Monitor serie muestra tres ángulos: el del acelerómetro (con ruido), el del giroscopio (que se va desviando con el tiempo) y el del filtro complementario, que es estable y sin deriva. El servo se mueve al ángulo del filtro.
