1 · El bus: todos en los mismos 2 cables

Juega: ¿a quién le habla el Arduino?

Toca un botón y mira quién contesta.
Pull-ups: I2C necesita resistencias (típico 4.7 kΩ) que suben las líneas a 1. Casi todos los módulos ya las traen.
Ejemplo práctico
Una estación con pantalla, sensor de clima y giroscopio: los tres comparten los mismos dos cables del Arduino. Agregar otro dispositivo no pide más pines, solo una dirección distinta.

2 · Direcciones: el número de casa

7 bits128 direcciones (unas 112 utilizables; las demás están reservadas). Es lo que usa casi todo.
1110110R/W
0x76 en binario + el bit de leer/escribir
10 bits1024 direcciones. Existe para instalaciones enormes, pero casi nadie lo usa en sensores.

Direcciones típicas

0x27 o 0x3FPantalla LCD con módulo I2C
0x3CPantalla OLED
0x76 o 0x77Sensor BME280
0x68 o 0x69IMU MPU6050
0x68Reloj RTC DS3231
0x29Sensor láser VL53L0X
Choque real: el RTC DS3231 y el MPU6050 usan la misma dirección (0x68). Conectados juntos, se estorban.
Ejemplo práctico: ¿cómo se arregla un choque?
1) Cambiar la dirección del módulo con su jumper o pin ADDR/AD0 (por ejemplo de 0x68 a 0x69). 2) Poner uno de los dispositivos en otro bus I2C. 3) Usar un multiplexor I2C, que enciende un dispositivo a la vez.

3 · La conversación: Start y Stop

1 · START«¡Atención, voy a hablar!» SDA baja mientras SCL está arriba.
2 · Dirección + R/W«Oye, 0x76, te voy a leer.» Un bit dice si es leer (1) o escribir (0).
3 · ACK«Aquí estoy.» El esclavo baja SDA para confirmar.
4 · DatosUn byte a la vez y cada byte se confirma con su ACK.
5 · STOP«Cambio y fuera.» SDA sube mientras SCL está arriba. El bus queda libre.
Regla de oro: SDA solo cambia mientras SCL está abajo. Si cambia con SCL arriba, eso es un Start o un Stop.
Ejemplo práctico: pedir la temperatura
El Arduino manda Start, luego «0x76 + quiero leer», el sensor contesta ACK, el Arduino recibe los bytes de temperatura (confirmando cada uno) y cierra con Stop. Todo pasa en una fracción de milisegundo.

4 · Cuando algo sale mal

Misma direcciónDos módulos con el mismo número contestan a la vez y la lectura sale basura.
Solución: cambiar la dirección de uno.
Dos maestrosHablan al mismo tiempo. Gana el que manda 0 mientras el otro manda 1, y el perdedor espera y reintenta.
Poco común en clase: casi siempre hay un solo maestro.
Nadie contesta (NACK)Cable suelto o dirección mal escrita: nadie confirma. Así funciona un escáner I2C.
Solución: revisar cables y dirección.
Bus trabado y timeoutUn esclavo se cuelga con SDA abajo y el bus se congela. El timeout dice «si no contestas en cierto tiempo, aborto y sigo».
Se recupera mandando pulsos de reloj hasta que suelte la línea.
Ejemplo práctico: sensor desconectado en pleno funcionamiento
Con el programa corriendo, alguien jala el cable del sensor. Sin timeout, el Arduino se queda esperando para siempre y toda la máquina se congela. Con timeout, detecta el error, avisa «sensor perdido» y el resto del sistema sigue trabajando.
